# Soporte Tecnico

Monorepo del sistema de gestion de solicitudes de soporte tecnico. Contiene el backend (API REST) y el frontend (Angular).

## Estructura

- [`backend/soporte-tecnico-api`](backend/soporte-tecnico-api) — API RESTful en Java 17 + Spring Boot 3 (Solicitudes, Clientes, Tecnicos).
- `frontend/` — Aplicacion Angular (interfaz web para clientes, tecnicos y administradores).

Cada carpeta tiene su propio README con instrucciones especificas de instalacion y ejecucion.
